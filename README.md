# FICHE DE PRÉSENTATION — PROJET AGRI-TOGO

## DIAPOSITIVE 1 — Présentation du projet

### AGRI-TOGO

**Site web vitrine d'une coopérative agricole togolaise**

**Technologies utilisées :**

* HTML5
* CSS3
* JavaScript natif (Vanilla JS)

### Contexte

AGRI-TOGO est une coopérative agricole fictive regroupant des producteurs des régions **Maritime et des Plateaux**.

La coopérative souhaite disposer d'un site web moderne, simple et responsive afin de :

* présenter la coopérative et ses valeurs ;
* mettre en avant ses produits ;
* partager ses actualités et événements ;
* faciliter le contact avec les acheteurs, partenaires et ONG.

### Public cible

* Acheteurs potentiels
* Restaurateurs et grossistes
* Particuliers
* Partenaires et ONG
* Jeunes agriculteurs
* Grand public togolais et international

# DIAPOSITIVE 3 — Réalisation et démonstration

## Choix techniques

### HTML5

Nous avons utilisé une structure sémantique avec :
`header`, `nav`, `main`, `section` et `footer`.

### CSS3

Nous avons utilisé CSS3 pour :

* la mise en page ;
* le responsive design ;
* l'adaptation aux mobiles, tablettes et ordinateurs ;
* la cohérence graphique du site.

### JavaScript

JavaScript permet de rendre le site interactif :

* ouverture et fermeture du menu hamburger ;
* validation du formulaire ;
* fonctionnement du carrousel ;
* fonctionnalités bonus.

### Organisation du projet

```text
agri-togo/
│
├── index.html
├── pages/
│   ├── a-propos.html
│   ├── nos-produits.html
│   ├── actualites.html
│   └── contact.html
│
├── css/
│   └── style.css
│
├── js/
│   └── script.js
│
└── images/
```

## Démonstration

Pendant la démonstration, nous allons montrer :

1. La navigation entre les différentes pages.
2. Le fonctionnement du menu hamburger sur mobile.
3. Le responsive design.
4. Le carrousel de la page « Nos produits ».
5. La validation du formulaire de contact.
6. Les fonctionnalités bonus réalisées.

## Conclusion

Notre objectif était de réaliser un site vitrine **fonctionnel, responsive et interactif**, tout en respectant les contraintes du cahier des charges et en utilisant uniquement **HTML5, CSS3 et JavaScript natif**.
